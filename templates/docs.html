Base URL & Authentication

All requests go over HTTPS. Send your secret key as a bearer token (or in an X-API-Key header). You can copy your key from the API Keys page.

BASE URL
{{ base }}
HEADER
Authorization: Bearer sk_live_xxxxxxxxxxxxxxxx
Keep the key on your server. Never put it in browser JavaScript, a mobile app or a public repo. If it leaks, generate a new one from the API Keys page; the old one stops working immediately.

Prerequisites — Connect Your Mailbox

Payments are confirmed by reading the credit alert email your UPI app sends. Connect that Gmail once on the Integrations page.

StepWhat to do
1Enable IMAP in Gmail: Settings → See all settings → Forwarding and POP/IMAP → Enable IMAP → Save. (direct link)
2Create a 16-letter Google App Password (needs 2-step verification).
3Open Integrations, enter the Gmail address, the App Password and your UPI ID (for example yourname@fam).
4Click Connect Gmail. The login is tested first; once it works the status turns to Connected.
Common gotcha: if IMAP is off, Gmail refuses the login even when the App Password is right. Check that setting first.

Create Order & Generate UPI QR

POST {{ base }}/api/v1/orders — only amount is required. Creating another pending order with the same order_ref and amount returns the existing one (HTTP 200) instead of a duplicate.

FieldTypeDescription
amountnumberrequiredAmount in INR, at most 2 decimals
order_refstringoptionalYour own reference (max 100 chars), echoed back in the webhook
notestringoptionalShort note shown in the UPI app (max 60 chars)
callback_urlstringoptionalWebhook URL for this order (overrides your default endpoints)
redirect_urlstringoptionalWhere the checkout page sends the customer after payment
expires_insecondsoptionalDefault 900 (15 minutes)

Verify Payment Status

GET {{ base }}/api/v1/orders/<order_id> returns the same object as create, with status of pending, paid or expired. Paid orders include utr and paid_at. Prefer the webhook; use polling as a fallback.

Webhooks

When a payment is matched we POST JSON to your endpoints. Respond with any 2xx status. Failed deliveries are retried up to 6 times with increasing delays, and you can retry manually from the Webhooks page.

PAYLOAD
{
  "event": "payment.success",
  "order_id": "ord_Ab3dE9xQz1k",
  "order_ref": "user42-premium",
  "amount": "499.00",
  "payable_amount": "499.00",
  "currency": "INR",
  "utr": "412345678901",
  "paid_at": "2026-01-01T10:03:11+00:00",
  "paid_late": false
}
Headers X-Timestamp and X-Signature: sha256=<hex> are sent. The signature is HMAC-SHA256 of timestamp + "." + raw_body using your signing secret. Always verify it, reject old timestamps, and make the handler idempotent on order_id because a webhook can be delivered more than once.
{{ tabs('hook', ['Python', 'Node.js', 'PHP']) }}
import hmac, hashlib, time
from flask import Flask, request, abort

app = Flask(__name__)
SECRET = "whsec_..."          # from your dashboard

@app.post("/payment-webhook")
def webhook():
    ts  = request.headers.get("X-Timestamp", "")
    sig = request.headers.get("X-Signature", "")
    body = request.get_data()                       # raw bytes, not re-serialised JSON
    if not ts.isdigit() or abs(time.time() - int(ts)) > 300:
        abort(400)
    expected = "sha256=" + hmac.new(SECRET.encode(), ts.encode() + b"." + body,
                                    hashlib.sha256).hexdigest()
    if not hmac.compare_digest(sig, expected):
        abort(401)
    data = request.get_json()
    # if data["order_id"] is not already fulfilled -> deliver the product
    return "ok"
const crypto = require("crypto");
const express = require("express");
const app = express();
const SECRET = "whsec_...";

app.post("/payment-webhook", express.raw({ type: "*/*" }), (req, res) => {
  const ts = req.header("X-Timestamp") || "";
  const sig = req.header("X-Signature") || "";
  if (!/^\d+$/.test(ts) || Math.abs(Date.now() / 1000 - Number(ts)) > 300) return res.sendStatus(400);
  const expected = "sha256=" + crypto.createHmac("sha256", SECRET)
    .update(ts + ".").update(req.body).digest("hex");
  const ok = sig.length === expected.length &&
    crypto.timingSafeEqual(Buffer.from(sig), Buffer.from(expected));
  if (!ok) return res.sendStatus(401);
  const data = JSON.parse(req.body);   // fulfil once per data.order_id
  res.send("ok");
});
